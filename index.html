Features Documentation

Charts that are part of your InDesign layout

ChartStyler builds charts from InDesign tables or CSV files as native InDesign objects, styled with your own object and paragraph styles. No pasted images, no round trips through other software.

Get started Read the documentation

Made for print design

ChartStyler works the way InDesign works, so charts fit your document, your styles and your workflow.

Native InDesign objects

Lines, shapes and text frames you can select, adjust and export like anything else on the page.

Your styles

Charts use InDesign's object and paragraph styles, so they match the rest of the publication.

Data you can see

Data lives in an InDesign table: paste it from Excel or import a CSV, and reload the CSV when the numbers change.

Always editable

Every chart keeps its settings. Select it, change the data or the design, and update it in place.

Two steps to a chart

  1. Put your data in an InDesign table Paste it in, or import a CSV file.
  2. Create the chart Pick a chart type and the table, set up the series and the design, and place the chart on the page.
