# Design → Series → Area

*(Shown for Area charts.)*

Controls how the area below each line is filled.

- **Area Style**: *To Zero* fills down to the zero baseline. *Stacked* fills to the previous series.
- **Area Opacity %**: transparency of the fill, from 0 (fully transparent) to 100 (opaque).
