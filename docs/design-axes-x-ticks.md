# Design → Axes → X Ticks

Controls the tick labels along the X axis.

- **Show tick labels**: toggles the X-axis tick labels on or off. The other options are available when this is on.
- **Tick Format**: choose automatic formatting or a preset such as integer, decimal, percentage, or scientific notation. When the labels are dates, the menu shows date presets instead. Choose *Custom…* to enter your own format; see [Custom number and date formats](design-axes.md#custom-number-and-date-formats).
- **Suffix**: text added after every X-axis tick label, for example `%` or ` km`.
- **Show every N labels**: shows only every Nth label, which is useful when categories are crowded.
- **Start at**: sets the first category or tick position to display.
