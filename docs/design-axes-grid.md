# Design → Axes → Grid

Controls the axis titles, grid and axis lines, and the range of the Y axis.

---

## Axis titles

- **X-Axis Label**: title displayed below the X axis.
- **Y-Axis Label**: title displayed to the left of the Y axis.

---

## Grid and axis lines

- **Show Grid**: displays horizontal grid lines at each Y-axis tick.
- **Show X-Axis Line**: draws a line along the bottom of the plot area.
- **Show Y-Axis Line**: draws a line along the left edge of the plot area.

---

## Y-axis range

- **Y Min / Y Max**: override the automatic Y-axis range. Leave blank for automatic.
- **Start Y from zero**: forces the Y-axis minimum to zero.
