# Design → Axes → Y Ticks

Controls the tick labels along the Y axis.

- **Show tick labels**: toggles the Y-axis tick labels on or off. The other options are available when this is on.
- **Number Format**: choose automatic formatting or a preset such as integer, decimal, percentage, or scientific notation. Choose *Custom…* to enter your own format; see [Custom number and date formats](design-axes.md#custom-number-and-date-formats).
- **Suffix**: text added after every Y-axis tick label.
- **Value step**: sets the distance between Y-axis ticks.
- **Start at**: sets the first Y-axis tick value.
