# Data → Series

Use the **Series** tab to tell ChartStyler how the rows and columns in your data source are arranged and how the values are read. A data series is a set of related values that are drawn together in the chart, such as the monthly sales figures. Each series gets its own line, set of bars, area or group of points, with its own colour and an entry in the legend.

It has four sub-tabs:

- [Select](data-series-select.md): data orientation, and which rows and columns hold labels, series names and values.
- [Adjust](data-series-adjust.md): reorder, include or exclude the detected series.
- [Processing](data-series-processing.md): decimal separator handling, and a preview of the data used for the chart.
- [Groups](data-series-groups.md): group individual data points to style them differently. Shown for Line, Area, Scatter and Bar charts.
